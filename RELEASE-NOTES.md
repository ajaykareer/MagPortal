# MagPortal 0.2.0

First public Windows release and browser player.

- Windows installer with desktop and Start menu shortcuts.
- Included runtime and server that start automatically with the app.
- Saved Windows app data encrypted with account protection.
- Sandboxed renderer, private server authentication, and restricted asset serving.
- Local scripts and disabled sensitive diagnostic logging.
- Saved profiles, favorites, progress, and backup import/export.

Download `MagPortal-Setup-0.2.0.exe` for Windows 10/11 (64-bit). The installer is unsigned. `SHA256SUMS.txt` contains its checksum.

Enter your own authorized provider details or import a playlist. This release contains no channels or shared subscriptions. Streams need formats supported by the included player.

The [browser player](https://magportal-player.goli15.chatgpt.site) supports compatible HTTPS sources, with provider browser permissions and session restrictions. It does not relay or transcode video. Saved web details are scoped to the browser tab.
